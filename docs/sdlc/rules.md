# Register of mandatory rules

Every rule: ID, stage, owning role, enforcement mechanism, reason, date, status.
Status (since v0.1, 2026-11-24): every rule starts as `experimental`. It becomes `established` once it has automatic enforcement (test, CI, hook or lint) and has come through one full iteration; the owner approves the change in the stage 8 review. Experimental rules are the first candidates to change or remove.
A critical rule must have automatic enforcement. A rule based only on an instruction is a recommendation and is marked as such.
Periodic review: rules that were not enforced are deleted or replaced. Every new rule needs a reason.
